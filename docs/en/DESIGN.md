# Design language

> Japanese is the source of truth: [日本語版](../DESIGN.md)

[Previous: Implementation architecture](ARCHITECTURE.md) · [Back to README](../../README.en.md)

This document defines the visuals, motion, and information expression of the ORRERY cockpit. For the structure of the implementation, see [Implementation architecture](ARCHITECTURE.md); for feature operations, see [Usage](usage.md).

## Concept: instrument panel × crew

ORRERY is a dark instrument panel for operating a crew of agents that have scientist identities. Its identity is to combine the precision of telemetry with the human warmth of portraits.

It aims for a calm cockpit that holds up under long hours of monitoring and operation, not an excessive cyberpunk neon.

## Typography

- display / agent name: `Fraunces`
- telemetry / chrome / terminal: `IBM Plex Mono`

Use an editorial serif for agent names, the wordmark, and panel headings, and mono for numbers, paths, labels, and the terminal. A fallback is acceptable when the font CDN is unreachable.

## Color

The whole is near-monochrome. Hue carries meaning, so its use is limited.

| token | value | use |
| --- | --- | --- |
| `--bg` | `#0b0d11` | near-black slate |
| `--ink` | `#ece5d6` | warm parchment text |
| `--amber` | `#f2b65a` | limited accent to draw attention |
| lineage local | `#5fb3a3` | spawn lineage |
| lineage remote | `#b58be0` | spawn lineage |
| lineage delegate | `#83b06a` | spawn lineage |

### Rules

- Color is reserved for identifying spawn lineage
- Do not distinguish working / waiting / idle by color alone
- Express state with motion, text, and icons together
- Maintain contrast, and do not make UI state depend on the colors of a portrait

## State and motion

| state / event | expression |
| --- | --- |
| working | rotation of the portrait ring |
| approval wait | blink of the ring and prompt, `⏎` |
| speaking | speech bubble with a typing cursor |
| idle | motion stops |
| live mail | comet on a lineage / mail edge |
| page load | staggered rise of crew tiles and mail cards |
| terminal focus | block cursor and a limited phosphor glow |

Respect `prefers-reduced-motion`, and keep the design so that state can be understood from text / icons even when motion is stopped.

## Chrome and locale

Navigation, panel labels, and control names use concise English.

```text
CREW
TERMINAL
AGENT MAIL
TELEMETRY
SETTINGS
```

Tasks, live output, mail, and content generated by agents keep the locale of the original text. The UI does not machine-translate content.

## Layout

Basic composition:

- Left: roster and search
- Center: terminal, session / pane tabs, prompt composer
- Right: ORRERY Mail rail
- header: agents (running / list), Usage pill, Settings, Planetarium, Telemetry, clock. The backend connection state appears only when it is not live
- overlays: jump palette, spawn, Planetarium, Settings, Usage dial, TELEMETRY

The Usage pill is the same pill as the other header utilities and holds only the % of the binding window for each provider. The text is 11px tabular, with three levels: emerald in `--ln-local` above 50% remaining, amber at 50% or below, and alert red at 20% or below. The dial opened by clicking shows the same values as arcs in the same three colors, with the number in lining figures at the center of the circle, and no decorative ring is added.

Split changes its layout according to the number of sessions handled at once. With 5 or more, font auto-shrink can be used, but it never goes below 9 px, so that readability is not lost for the sake of information density.

## Terminal

Inset shadow, scanlines, and phosphor glow are used only on the terminal screen, and the whole screen is not decorated. The ANSI colors of terminal output are preserved and separated from the chrome so that they do not compete with the cockpit's lineage colors.

The Claim / Follow state is made explicit as an operation that affects the tmux window size, not as a display layout state.

## Portrait

Scientist portraits are shown as round medallions, blended into the palette with a light grayscale / sepia and a vignette. When there is no image, an initials SVG is used.

Distinguish the normal, high-resolution, and pixel-style asset sources, and match them to the actual directory names `portraits_64`, `portraits`, and `portraits_px`. For sources listed in the manifest, the manifest and [CREDITS.md](../../CREDITS.md) are the source of truth for the author, license, and conversion information. Portraits not listed are not used in the distributed UI. However, the 50 pixel-art portraits in `assets/portraits_px/` were generated by the author, gyroid, with ChatGPT (OpenAI image generation) from text instructions alone. No photographs were used as input. They are distributed under the same terms as the repository (PolyForm Perimeter License 1.0.1).

A portrait alias does not indicate a provider tier or subscription. Do not infer and display an agent's capability, price, or contract from its portrait name.

## Mini-orrery and Planetarium

The spawn forest is shown as the topology, and recent mail as temporary edges / comets.

- Node color is lineage
- Node motion is state
- Clicking a node jumps to the agent
- The mini is for constant awareness, and the Planetarium is for exploration
- Telemetry network mode shows 1 to 3 hops from an active agent

When labels overlap with many nodes, disclose details on hover / focus instead of adding always-on labels.

## Agent Mail

A mail card shows the subject, sender, importance, and time first, and the body opens in the detail view. Markdown is rendered only as a safe, limited subset.

Mail can contain confidential information, so priority goes to visibility and a close operation that reduce accidental exposure during screen sharing. Do not let the control affordances suggest that this rail has reply / send; it is a read-only rail.

## Accessibility

- Do not convey state by color alone
- Make the palette, terminal, composer, and modals operable by keyboard
- Do not remove focus rings
- Keep state readable even with reduced motion
- Do not allow a terminal font below 9 px
- Close overlays with `Esc` and return focus to the original control

## Checks when changing

For a visual change, check the following.

1. Lineage color and state expression are not confused
2. The ring and label are readable on both light and dark portraits
3. The terminal is operable in the 1, 2–4, and 5–12 session layouts
4. Degradation in the cases of ORRERY Telemetry offline, mail empty, and portrait missing does not leave a blank
5. The main operations can be completed with the keyboard and with reduced motion
6. The cause can be diagnosed even when third-party fonts / xterm are unreachable
